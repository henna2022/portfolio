닥터그린 (doctor-green)doctor-green

작물 병해충을 영상으로 진단하는 AI 모듈과, 재배 환경을 실시간 계측·제어하는 IoT 디바이스를 단일 웹 플랫폼에서 통합 운용하는 스마트팜 플랫폼입니다. ESP32 센서 노드가 환경 데이터를 수집하면 중계 서버를 거쳐 Supabase에 적재되고, Next.js 웹앱에서 실시간으로 시각화됩니다.A smart-farm platform that unifies an AI module diagnosing crop diseases from images with IoT devices that measure and control the growing environment in real time. ESP32 sensor nodes collect data, relay it through a server into Supabase, and a Next.js web app visualizes it live.

🗺️ 시스템 구조도 / 아키텍처 다이어그램 System architecture diagram

주요 내용Highlights

  • 데이터 흐름: IoT 센싱 → Mac 중계 서버(Flask) → Supabase 적재 → Next.js 웹앱 실시간 시각화Data flow: IoT sensing → Mac relay server (Flask) → Supabase → real-time Next.js visualization
  • USB 카메라 영상에 YOLOv8을 적용해 작물 병해충 7종 탐지·진단Applied YOLOv8 to USB-camera video to detect and diagnose 7 crop-disease classes
  • 웹앱에서 LED·팬 등 액추에이터를 Supabase Realtime 구독으로 실시간 제어Real-time actuator control (LED, fan) from the web app via Supabase Realtime
  • YOLOv8 1차 학습(50 epoch) mAP50 ≈ 0.95 달성, 2차 YOLOv8l(150 epoch) 고도화 진행 중1st training (50 epoch) reached mAP50 ≈ 0.95; 2nd YOLOv8l (150 epoch) in progress
  • Roboflow strawberry-disease-detection-dataset v4 활용, 클래스 불균형 대응 증강 전략 적용Used Roboflow strawberry-disease-detection-dataset v4 with augmentation for class imbalance
