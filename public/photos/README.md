# 홈 사진 넣기

목록 원본: `lib/photos.ts`. 아래 파일명 그대로 JPG 사진을 넣으면 코드 수정 없이 표시됩니다.
`next dev`에서는 새로고침, 정적 배포에서는 다시 빌드해야 반영됩니다. 파일이 없으면 같은 비율의 안내 상자만 표시하며 사진 요청은 보내지 않습니다.
사진은 상자를 채우도록 잘리므로 중요한 피사체를 중앙에 두세요.

  - 태블릿이나 키오스크를 사용하는 손 또는 뒷모습을 권장합니다. 어린이 얼굴은 동의가 있는 경우에만 사용합니다.

- 사진 ② 강의·멘토링 현장
  - 가로 4:3 · 1600×1200 이상

  - 수업이나 멘토링 중인 장면을 담습니다. 학생의 손이나 뒷모습을 권장하며, 어린이 얼굴은 동의가 있는 경우에만 사용합니다.

  - 이주원이 전시를 안내하는 세로 사진을 담습니다. 어린이 관람객은 뒷모습을 권장하며, 얼굴은 동의가 있는 경우에만 사용합니다.
