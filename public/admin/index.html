오래된 통계 정리

          
통계 삭제는 보안 설계상 이 페이지(API)에서 불가능합니다 — 실수·계정 탈취에 대비해 RLS에 DELETE 정책을 두지 않았습니다. 필요할 때 아래 SQL을 Supabase SQL Editor 에서 실행하세요.

          
-- 180일 지난 방문·이벤트 삭제
delete from page_views where created_at < now() - interval '180 days';
delete from events     where created_at < now() - interval '180 days';
